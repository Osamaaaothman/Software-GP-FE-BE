# Software GP — Frontend & Backend

Graduation-project codebase containing a Node.js backend and two client apps (a website and a mobile app).

## Structure

```
backend/             Node.js API (src, DB scripts)
frontend/website/    Web client
frontend/mobile/     Mobile client
```

## Run locally

```bash
cd backend
npm install
node index.js
```

Create your own `.env` for database and secrets before starting; each frontend has its own `package.json` with install and start instructions.
